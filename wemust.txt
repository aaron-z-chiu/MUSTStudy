第⼆章︓API基礎知識
2.1 API概述和架構
API（Application Programming Interface，應⽤程序編程接⼝）是不同軟件組件之間通信的橋樑。WeMust AI
API採⽤RESTful架構設計，這意味著它使⽤標準的HTTP⽅法（如GET、POST）來處理請求，並以JSON格式交換
數據。
API架構圖︓

你的應⽤程序 → HTTP請求 → WeMust AI API → AI模型處理 → 返回結果 → 你的應⽤程序

核⼼概念︓
1. 端點（Endpoint）︓API的具體地址，每個端點負責特定的功能
2. 請求（Request）︓你發送給API的數據和指令
3. 響應（Response）︓API返回給你的結果
4. 認證（Authentication）︓證明你有權使⽤API的機制
5. 模型（Model）︓執⾏AI任務的具體算法，如GPT-4o、GLM-4等
API版本管理︓ WeMust AI API⽬前使⽤v1版本，所有API路徑都以/v1開頭。這種版本管理⽅式確保了向後兼
容性，即使API更新，你的現有代碼仍然可以正常⼯作。

import time
import random
def retry_with_backoff(func, max_retries=3):
for attempt in range(max_retries):
try:
return func()
except Exception as e:
if attempt == max_retries - 1:
raise e
wait_time = (2 ** attempt) + random.uniform(0, 1)
time.sleep(wait_time)
