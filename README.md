# MUSTStudy: A Curriculum‑Aligned Learning Hub for CS Student @ MUST
Final Project for SE Course @ SCSE, FIE, MUST\
Qiu Zecheng, Wu Yutong, Chen Haopeng, Ai Zerun

## Project Description

### Overview
MUSTStudy is a curriculum-aligned learning hub that curates and annotates high-quality videos, notes, and exercises, mapping them precisely to the Bachelor of Science in Computer Science at Macau University of Science and Technology (MUST). 

### Key Features
*	Syllabus-Aligned Mapping with Timestamped Out-Links: Students browse the course by syllabus items and open direct, time-coded links to the precise portions of external resources that correspond to each item; bilingual alternatives are offered where useful. This eliminates guesswork about relevance and order. 
*	Prerequisite Bridge: Before tackling a mapped item, students complete a short ramp-up and self-check on assumed competencies (e.g., Java basics, Git workflow, build & dependency, unit testing/CI, troubleshooting). Those who do not pass are guided to repair prerequisites first. 
*	Multi-OS Readiness: Students follow step-by-step validation guides for Windows/macOS/Linux toolchains, so assignments are not blocked by environment issues. 
*	Learn–Track–Reflect: After studying, students check in and monitor progress on the Achievement page (Overview, Progress, Daily Attendance, Today’s Stats, Heatmap). The app surfaces momentum and gaps without extra effort, supporting the evaluation metrics above.
